{% docs int_localbike__stores %}

Ce modèle fournit une vue descriptive des magasins en centralisant les informations géographiques et d’identification. 
Il permet d’analyser la performance et la répartition des activités par point de vente et par zone géographique.

Il inclut les champs suivants :

store_id : Identifiant unique du magasin.
store_name : Nom du magasin.
city : Ville dans laquelle le magasin est situé.
state : État ou région du magasin.
